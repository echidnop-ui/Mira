HEIWA LIVE DEVELOPMENTAL LANGUAGE DIALOGUE

Adds:
  language/developmental.py
  runtime/language_live_dialogue.py
  patches/live_language_handoff.patch

The runtime performs one real developmental language turn:
  Heiwa own generated attempt
  -> visible ChatGPT mentor
  -> explicit correction
  -> local GPU learning
  -> Heiwa own retry
  -> visible ChatGPT evaluation

Install:

  cd ~/heiwa_v2
  unzip -o ~/Downloads/HEIWA_LIVE_DEVELOPMENTAL_LANGUAGE_STEP.zip -d ~/heiwa_v2

  patch --dry-run -p1 < patches/live_language_handoff.patch
  patch -p1 < patches/live_language_handoff.patch

  source .venv-rocm/bin/activate
  python -m py_compile language/developmental.py runtime/language_live_dialogue.py

Run one live turn:

  python -m runtime.language_live_dialogue --local-steps 24

Keep the intended ChatGPT conversation visible in Firefox.

Important:
- attempt/retry text is generated by Language; there is no canned fallback;
- failed own output is not teacher data;
- mentor correction is explicit teacher data;
- target meaning is a developmental teacher scaffold, not a hardcoded desire;
- current V2 checkpoint is used only as a seed when present;
- developmental learning is saved separately to state/language_developmental_dialogue.pt;
- raw mentor transcript is not persisted as autobiography.
